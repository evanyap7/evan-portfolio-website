Overview

A fan taps a borderline call, such as a penalty, and asks “what if it wasn’t given?”. The screen splits into the real match and an alternate one, with the change in win chance and its 95% interval. Every club and player is synthetic.

What I built

  • Simulator and what-if engine

    A seeded match generator, and an engine that replays a match to one moment, changes the call and plays the rest hundreds of times. Each pair shares its random numbers, so the difference is the call, not luck.

  • Agent desk

    Agents draft the commentary, the Law explanation and the season precedent. A fact-checker agent verifies every number before it is shown. All numbers come from code, never from a model.

  • API and 18-language interface

    The API behind the viewer, and an interface in 18 languages where the agents answer in the fan’s choice.

Stack
