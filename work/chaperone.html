Chaperone

Chaperone is an oversight agent that sits between a one-person company's AI worker agents and the outside world. Each action goes through one logged gate that classifies the data, checks the facts and returns allow, hold or block, with the source file quoted. Built for the QwenWork x Hashmeta AI One-Person Company Hackathon, Track 2.

Overview

A single gate that checks every worker-agent action and logs why.

Agents thatanswerto someone.

What it does

The gate
Classifies data by content, tracks lineage, checks task scope, fact-checks figures, aggregates payments and scans for injection.
Decisions
ALLOW, HOLD_FOR_APPROVAL or BLOCK under 19 policy rules. NEVER rules can't be approved by anyone.
Owner control
Only the signed-in owner can decide real queue items. Approvals are single-use. Visitors get a sandboxed demo mode.
Audit log
Append-only and hash-chained. It records the agent, action, files, data level, rule IDs and quoted evidence.
Scenarios
Ten scenarios, including a payment split, a fake owner approval and prompt injection, all scored on decision, rules and evidence.
Integration
A QwenWork PreToolUse hook routes tool calls through the gate. The live app runs on QwenWork Pages.
