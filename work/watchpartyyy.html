Overview

A Chrome extension that keeps play, pause and seek in sync for friends watching Netflix together, with a small chat panel. It only syncs the controls and never touches the video, so everyone uses their own subscription.

What I built

  • Sync that Netflix accepts

    Netflix rejects direct writes to the video’s time, so a script in the page calls Netflix’s own player API instead. The content script watches the video and applies each event from the room.

  • Relay server

    A Node WebSocket server that keeps each room’s latest playback state in memory, so a friend who joins late catches up straight away. It runs in Docker on Fly.io.

  • Working around Netflix’s limits

    Netflix’s page policy blocks WebSockets from the content script, so a background script owns the connection. The injected chat panel and the undocumented player API can change, which I list as known limits.

Stack

JavaScript · Chrome extension (Manifest) · Node · WebSocket (ws) · Docker · Fly.io
