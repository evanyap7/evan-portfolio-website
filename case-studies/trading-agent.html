Case study · Systematic Trading System · Python

I built a trading system, tested four ideas for an edge, and found none.

A trading system for a small Webull Singapore account, where no model can size or place an order. I tested four ideas for an edge on it, including a Claude agent. None beat holding the S&P 500, so it now runs in shadow mode.

The short version

  • What I built. A swing-trading system where the agent may only propose. Deterministic code verifies, sizes and risk-checks every idea, and an append-only ledger records each step. It placed its first real orders in September 2026, one share at a time.
  • What I tested. Four ideas for an edge: a Claude agent, classic quant signals, insider buying from SEC filings, and the plain momentum rule the system runs now.
  • What I found. No edge. Claude did not beat the free rule and cost about $27 a year, so I removed it. No classic signal survived out-of-sample testing and a correction for luck, and insider buying added nothing once sizing and stops applied.
  • The uncomfortable part. The momentum rule returned +66.8% against SPY's +70.1% from 2022 to 2026, at about half the drawdown. Across the classic quant signals I tested, the best deflated Sharpe was 0.65, below my bar of about 0.95. I report that as the result, and the system stays in shadow mode.

How it is built

The agent may only propose a trade. Deterministic code verifies, sizes and risk-checks every proposal, and a tamper-evident ledger records each step. In the version I tested, trade proposal was the only step that used a model. It is now a rule behind the same checks.

Four design decisions

  • The proposer cannot size or send an order. An independent verifier rejects anything ungrounded, stale, mispriced or without edge after costs. Size comes from quarter-Kelly, capped at 2% risk per trade.
  • The risk limits are a file the agent cannot write. They change only through a human git commit, and every risk decision records the file's hash.
  • Execution never retries blindly. Order IDs are deterministic, every order is previewed, and an ambiguous broker answer is resolved by asking the broker, not by resending.
  • The audit trail is tamper-evident, and the kill switch is a file. The ledger is insert-only and hash-chained, so an edit breaks the chain. Creating state/KILL stops new orders without touching the running process.

Four tests for an edge

Each idea ran on liquid US stocks and ETFs, and each had to beat simply holding the index. None did.

Four studies testing for an edge, and what each found
IdeaResult
Claude agent, against a free momentum ruleNo edge. Sharpe of 1.39 against 1.36 for the baseline and 1.89 for SPY, a lower win rate, and about $27 a year. Removed.
Momentum, reversal, low volatility and trend followingNo edge out of sample. Deflated Sharpe of 0.05 to 0.65, all below the bar. Trend following cut risk, not return.
Insider buying, from SEC Form 4 filingsNo usable edge. A small raw effect, mostly survivorship and noise, gone once sizing and stops applied.
The momentum rule the system runsMatches SPY and does not beat it: +66.8% against +70.1% from 2022 to 2026, at about half the drawdown.

How I kept a negative result trustworthy

  • No lookahead, and a test for it. The test rewrites the future of a price series and checks that no past signal moves.
  • Walk-forward selection. Settings are chosen on two years of data, scored only on the next six months, then rolled forward.
  • A correction for luck. The deflated Sharpe ratio counts every variant I tried, so each new grid raises the bar for the next.
  • Stated biases. The universe is today's survivors, which flatters every absolute return, and each report lists that under its caveats.

The Claude test

I replayed 2024 over the 100 most liquid US stocks, starting from $1,500, and set the bar before the run: the Claude agent had to beat the momentum baseline on both Sharpe ratio and win rate. It did not.

Claude's Sharpe lead of 0.03 is noise, its win rate was lower, and it cost about $27 a year on a $1,500 account. Its one real advantage was roughly half the drawdown. So I removed the model and kept the harness that told me the truth.

Caveats: one year in a strong bull market, and one run of a nondeterministic model.

A mistake worth reporting

My first comparison was invalid. The harness never loaded the API key, so every model call failed, and the backtester swallowed each error as "no trade". It printed a fake 0% win rate for Claude. The harness now records the first error of each kind and aborts if an agent only produces errors.

Where it stands

The system placed its first real orders on 23 September 2026, one share at a time, each with a broker-side stop. I switched live trading off on 1 October, and it now runs in shadow mode, recording decisions without sending orders. I would rather say that plainly than tune until a chart looks good.
