  3. 3

    Autonomous Trading Agent

    Developer · Sept 2026 112 symbols backtested before I removed the LLM layer

    A swing-trading agent for a Webull Singapore cash account, built so that no model can size or place an order. Deterministic code verifies, sizes and risk-checks every idea, and a hash-chained ledger records each step. I first built it around Claude agents, backtested them against a plain momentum rule on 2024 data, found no measurable edge for about $27 a year, and removed the LLM layer.

    Automated tests, run in CI on every push

    Symbols in the 2024 backtest
    112
    Yearly API cost of the LLM layer I measured, then removed
    ~$27

    Python, Pydantic, SQLite, pytest, Webull OpenAPI SDK, Databento, Telegram Bot API

  4. 4

    Decarbonisation Research Agent

    Full-stack developer · Aug 2026 0–100 truth rating on every claim, from retrieved sources only

    A research tool I built for a company’s energy engineers and decarbonisation consultants. Ask about a client facility, or paste in an ESG claim, and it retrieves the relevant public reports and PDFs, then answers only from what it retrieved: a cited research brief, or a verdict on the claim with the evidence on each side. Any finding that cites a source it did not retrieve is dropped, and it states what the evidence does not cover.

    5
